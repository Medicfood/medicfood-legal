# medicfood-legal

Public copy of the MedicFood Privacy Policy and Terms of Service, served with GitHub Pages.

- Privacy Policy: https://medicfood.github.io/medicfood-legal/privacy-policy
- Terms of Service: https://medicfood.github.io/medicfood-legal/terms-of-service

These files are generated from the app (`lib/legal/legal_documents.dart` in the private app repository, via `dart run tool/export_legal.dart`). Edit them there, then copy `docs/*.md` here (keeping the front matter at the top of each page).
